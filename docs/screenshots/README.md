# CodeOrbit — Application Screenshot Specifications

This directory holds official screenshots of the CodeOrbit web application for use in documentation, community presentations, and README showcases.

## Recommended Screenshots to Capture

Capture these screenshots from the live application at [https://codeorbit-c7q4.onrender.com](https://codeorbit-c7q4.onrender.com) (or local `http://localhost:3000`):

| File Name | View / Section | Viewport & Focus |
| :--- | :--- | :--- |
| `dashboard.png` | **Command Center** | Desktop (1440x900) full overview showing the cosmic hero, telemetry KPIs, velocity ring, and recent flightpaths. |
| `orbital-visualization.png` | **Orbital Skill Universe** | Focused capture of the animated planetary orbital rings and central developer core. |
| `skill-universe.png` | **Skill Universe (`#skills`)** | Desktop view of skill cards, proficiency tier tags, category filters, and search bar. |
| `mission-logs.png` | **Mission Logs (`#progress`)** | View of the daily goal circular gauge, activity stats, and chronological timeline logs. |
| `space-missions.png` | **Space Missions (`#projects`)** | Showcase of active flightpaths, progress bars, technology badges, and repository links. |
| `milestones.png` | **Milestones (`#goals`)** | View of milestone target horizons, priority badges (Critical, High, Medium, Low), and overdue indicators. |
| `universe-analytics.png` | **Universe Analytics (`#analytics`)** | Full dashboard view showing the 5 Chart.js visualizers and automated developer habit insights. |

## Capture Guidelines

- **Resolution:** 1440px width (or standard 1080p browser window).
- **Format:** Optimized `.png` or `.webp` for crisp text and high-contrast dark space background.
- **Browser State:** Load the built-in demo data from **Settings $\rightarrow$ Load Demo Universe** prior to capturing for populated, realistic metrics and populated charts.
